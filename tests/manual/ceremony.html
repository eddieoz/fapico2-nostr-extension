fapico2 Nostr — hardware ceremony

The manual release gate (US-1709). Board flashed with fapico2 feat/nostr, served from the repo root (e.g. python3 -m http.server) — the ordered steps block on failure:

init (capFlags 0x00, version 0.1.0) → generate key (touch) → getPublicKey → signEvent (touch, verified against nostr-tools) → nip44 encrypt/decrypt round trip (touch) → delete key (touch, npub echo checked).
